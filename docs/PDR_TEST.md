# 브라우저 PDR 실험

집에서 빠르게 확인하려면 **추천점에서 센서 켜기**를 누르고 권한을 허용한다. 절대 나침반이 들어오면 휴대폰이 향한 동·서·남·북을 표시한다. 1·3층에서는 지도 방향도 잠정 자동 보정한다. 절대 나침반이 없으면 첫 기기 방향을 기준으로 상대 이동만 표시하고 동서남북은 미확정으로 표시한다. 목적지 없이도 걸음 수와 상대 이동을 확인할 수 있다.

1·3층은 동광장·서광장의 지도 좌표와 후보 지리 좌표로 나침반을 지도에 자동 정렬한다. 후보 지리 좌표는 검증되지 않았으므로 자동 정렬도 잠정값이다. 2·4층은 기준점이 부족해 상대 방향 이동만 표시한다. 나침반은 휴대폰이 향한 방향이며 실제 보행 방향과 다를 수 있다. iPhone의 `webkitCompassAccuracy`가 25°보다 크면 방위 불확실성을 표시하고 오차 범위를 키운다. 화면의 동서·남북 미터 값은 출발점을 원점으로 한 상대 추정량이며 절대 지리 좌표가 아니다.

목적지를 선택하면 기존 다익스트라 결과의 각 선분을 지도 회전각으로 지리 방위에 변환한다. 지도 위와 경로 설명에 동·서·남·북의 대략적인 진행 방향을 표시한다. 실제 걸음이 감지될 때만 절대 나침반과 현재 경로 구간을 비교한다. 기본 60° 이내는 대체로 일치, 기본 75° 이상 차이가 3걸음 지속되면 **경로 이탈 의심**으로 표시한다. 나침반 정확도가 주어지면 허용 각도를 넓혀 경고를 보수적으로 판단하며, 오차가 45°를 넘으면 방향 비교를 보류한다. 나침반만으로 위치나 이탈을 확정하거나 자동 재탐색하지 않는다. 자동 재탐색은 별도로 검증된 거리 보정과 통로 매칭 조건을 만족할 때만 가능하다. 2·4층이나 절대 나침반이 없는 경우에는 이 방향 비교를 보류한다.

`/pdr-test.html`은 대전역 예시 SVG 평면도와 층별 `gps-test-floor-*.json` 그래프를 사용한다. 실제 집의 벽이나 통로를 인식하지 않는다. GPS는 요청하지 않으며 센서와 시험 기록은 브라우저 메모리에서만 처리한다.

## iPhone Safari 현장 절차

1. HTTPS 주소로 페이지를 연다. PC의 `localhost`는 휴대폰에서 접근할 수 없다.
2. 층과 출발점(추천점은 변경 가능)을 선택하고, 통로 후보를 확인해 위치를 확정한다.
3. 목적지를 고르고 경로를 표시한다.
4. **추적 시작**을 눌러 동작 및 방향 센서 권한을 허용한다. 권한 요청은 이 버튼의 클릭 안에서 실행된다.
5. 휴대폰을 걷는 방향으로 들고 나침반 동·서·남·북과 정확도 표시를 확인한다. 큰 방향 변화가 생기면 폰 회전과 실제 회전을 자동 구분할 수 없어 지도 이동을 보류한다.
6. 5m 직선, 90도 회전, 제자리 폰 회전을 각각 시험하고 고급 설정의 실제 거리·회전값을 기록한다. JSON을 내려받아 걸음, 센서 값, 지도 추정, 통로 후보를 비교한다.

Android Chrome도 HTTPS가 필요하다. 브라우저나 기기가 센서 값을 제공하지 않으면 모의 이동과 수동 출발점 선택을 사용할 수 있다.

## 좌표와 한계

지도와 그래프의 좌표는 층마다 다르다. 그래프의 `selectedDistanceM`에서 층별 SVG/m 비율을 임시 계산하지만 이 거리 데이터는 현장 검증되지 않았다. 고급 설정에서 실제 두 지점 사이의 거리를 입력하고 지도에서 두 지점을 고르면 해당 층의 실험 비율로 대체한다. 보정 전에는 통로 이탈과 재탐색을 보류한다.

걸음 검출은 가속도 피크의 주기성을 이용한 초기 POC다. 폰을 흔들거나 주머니에 넣으면 오탐과 누락이 가능하다. 방향 센서는 폰 회전과 몸 회전을 확실히 구별하지 못한다. 큰 방향 변화는 자동 이동을 보류하고 사용자 재확인을 요구한다. 교차·중첩 통로와 큰 위치 오차에서도 매칭을 보류한다.

걸음 수가 0이면 화면의 **동작 센서 진단**에서 수신 건수와 피크 수를 확인한다. 수신 건수가 0이면 권한·브라우저 센서 문제다. 수신은 있지만 피크가 0이면 센서 신호가 임계값에 못 미친 것이므로 민감도를 조정한다. 피크는 있는데 걸음이 0이면 피크의 간격·주기성 조건을 검토한다. 원시값과 JSON 기록을 비교해 기기별 감도 차이를 측정한다.

PDR 좌표는 3초 간격으로 받는 값이 아니라 감지된 걸음마다 계산한다. 시작점이나 방향 센서 값이 없으면 걸음만 기록하고 지도 이동은 보류한다. 절대 나침반이 있으면 동서남북과 지도 방향을 맞춰 추정 위치를 이동한다. 절대 나침반이 없으면 첫 기기 방향을 임의 지도 위쪽으로 삼아 상대 회전과 걸음만 시험한다. 이때 지도 점은 움직이지만 실제 동서남북과 정렬되지 않으며, 화면에 **동서남북 미확정**으로 표시한다. 폰이나 몸이 크게 회전하거나 나침반 오차가 크면 불확실성 원을 키우고, 경로와 다른 방향이 여러 걸음 지속되면 이탈 의심 경고만 표시한다. 폰이 향한 방향과 실제 보행 방향은 다를 수 있다.

3층 전체 도면에서는 한 걸음이 화면상 약 1픽셀 정도로 보일 수 있어, 방향이 있는 걸음이 기록되면 출발점 주변으로 지도를 자동 확대한다. 확대 화면은 출발점에 고정해 걸음에 따른 점의 움직임이 보이게 한다. **지도 이동** 칸에서 출발점으로부터의 추정 이동 거리와 보류 사유를 확인한다. 확대 버튼으로 전체 지도를 다시 볼 수 있다.
