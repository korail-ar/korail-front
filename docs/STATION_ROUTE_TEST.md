# 대전역 3층 길찾기 테스트

## 실행

Node.js 22 이상에서 `npm start`를 실행하고, 출력된 포트의 `http://127.0.0.1:3000/station-route`를 PC 브라우저에서 엽니다. 3000번이 사용 중이면 서버가 다음 빈 포트를 출력합니다. 검색어 `서문 엘리베이터`, `매표소`로 시설을 각각 선택한 뒤 **경로 보기**를 누릅니다. 입력을 서로 바꿔 역방향도 확인합니다.

휴대폰 GPS는 이 프로젝트를 HTTPS 호스팅에 배포하거나 로컬 서버에 HTTPS 터널을 연결한 뒤 `https://.../station-route`에서 테스트합니다. 브라우저 위치 권한을 허용하고 **내 위치 켜기**를 누릅니다. 권한 거부 상태도 같은 버튼으로 재현할 수 있습니다. `localhost`도 보안 컨텍스트이지만, 휴대폰에서 PC의 `localhost`는 PC 서버가 아닙니다.

## GPS 기준점 파일

[`public/gps-anchors.json`](public/gps-anchors.json)은 빈 배열로 시작합니다. 검증된 3층 기준점을 다음 형태로 추가합니다.

```json
[
  {"floor":3,"lat":36.0,"lng":127.0,"x":500,"y":400},
  {"floor":3,"lat":36.0,"lng":127.001,"x":700,"y":400},
  {"floor":3,"lat":36.001,"lng":127.0,"x":500,"y":600},
  {"floor":3,"lat":36.0005,"lng":127.0005,"x":600,"y":500,"role":"validation"}
]
```

위 숫자는 **형식 예시일 뿐 실제 기준점이 아닙니다.** 현장 측량으로 얻은 위경도와 지도에서 확인한 같은 바닥점의 픽셀 좌표를 넣습니다. 계산에 쓰는 점은 비공선 3개 이상이어야 합니다. 독립 검증점에는 `"role":"validation"`을 지정하면 보정에 사용하지 않고 오차를 픽셀로 표시합니다. 정확도 허용치는 `station-route.js`의 `MAX_ACCURACY_M`(초기값 30 m)입니다. 기준점 위경도의 최소·최대 영역 밖에서는 위치 점을 숨깁니다.

## 확인 범위

- 그래프 검색 및 다익스트라 계산: 서문 엘리베이터(`P43`) → 매표소(`P32`)와 역방향 모두 경로가 나옵니다.
- 초기 빈 기준점: 아핀 변환이 생성되지 않아 GPS 값만 표시하고 지도 위치 점은 표시하지 않습니다.
- 실제 휴대폰의 권한 허용·거부, GPS 수신 품질, 현장 기준점 보정 오차는 HTTPS 접속 가능한 휴대폰과 검증된 기준점으로 현장에서 확인해야 합니다.
