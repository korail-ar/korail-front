# 3층 직각형 경로 검증 기록

`scripts/build-walkable-plan.py`는 현재 `web-3F-map.svg`의 바닥 윤곽과 매장 사각형 41개를 추출한다. 이 마스크는 평면도 기반 후보 검사 자료이며 현장 통행 가능 여부의 확정 자료가 아니다. `orthogonalRoute.ts`는 원본 Edge의 양 끝 연결을 유지하고, 코너가 원본 선분에서 24 SVG 단위 이내이며 두 직각 선분이 마스크 안에 있을 때만 표시용 코너를 추가한다.

| 경로 | 원본 | 평면도 검사 후 | 보정 필요 |
| --- | --- | --- | --- |
| 3층 맞이방 `C01` → 9·10번 홈 연결점 `P18` | 10개 직선 Edge | 4개 Edge를 직각 후보로 표시 | 6개 Edge |
| 3층 맞이방 `C01` → 매표소 `P22` | 3개 직선 Edge | 안전하게 직각화할 Edge 없음 | 3개 Edge |

10번 승강장 경로에서 직각 후보로 처리한 Edge: `H06-H05`, `H04-H03`, `B02-B03`, `P15-P18`.

보정이 필요한 Edge: `C01-H07`, `H07-H06`, `H05-H04`, `H03-B01`, `B01-B02`, `B03-P15`. 매표소 경로에서는 `C01-H07`, `H07-H06`, `H06-P22`가 대상이다. 원본 사선을 그대로 표시하며 안내 화면에 평면도 통로 연결 확인 문구를 표시한다.

## 다음 데이터 작업

1. 각 Edge가 지나는 실제 통로의 중심선과 코너 위치를 현장 또는 검증된 도면에서 확인한다.
2. 통로가 직각이면 확인된 코너 Node와 두 보행 Edge를 그래프에 추가한다. 실제 사선 통로라면 사선 Edge를 유지한다.
3. 매표소와 매장의 실제 출입문 위치, QR 시작점, 계단·승강기 진입점을 확인한다.
4. 1·2·3층 연결 Edge와 접근성 속성을 검증한 뒤 층간 안내를 활성화한다. 현재 결합 그래프에는 층간 Edge가 없다.

Figma의 플라잉스콘·매표소 4단계 화면은 인터랙션과 시각적 기준이다. 현재 그래프에서 검증되지 않은 스팟, 사진, 직각 경로를 실제 데이터로 추가하지 않는다.
