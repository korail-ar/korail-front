# 현장 검증 필요 항목

1. **층별 축척과 시간:** 공통 0.1049m/SVG 단위, 보행 4km/h, 엘리베이터 대기 30초 및 층고 4m는 추정이다. 동일 지점 간 실측으로 층별 축척과 접근·대기 시간을 재보정해야 한다.
2. **시설 출입구 59건:** 현재 3층 시설의 `routeNodeId`는 접근 통로 지점이며 실측 출입구가 아니다. 여러 출입구와 문턱·휠체어 이용 가능 여부를 조사해야 한다. 확인 전 배리어프리 시설 도착을 확정하지 않는다.
3. **2층:** `2F-E012`의 형상이 없어 비활성화되었고 2개 노드가 분리됐다. 2층으로 정차하는 검증 엘리베이터 링크도 없어 2층 배리어프리 경로는 제공할 수 없다. 현장 연결 확인 없이 활성화하지 않는다.
4. **1층 외곽:** `1F-E023`, `1F-E025`, `1F-E026`, `1F-E027`, `1F-E029`는 SVG 건물 바닥 윤곽 밖을 지난다. 야외 보행·벽·장애물·출입 통제를 확인해야 한다.
5. **4층 및 층간 접근부:** 4층 좌표 정합, 계단·에스컬레이터 진입 방향, 엘리베이터 실제 정차 층과 접근 통로를 확인해야 한다. 현재 층간 시간에는 추정 접근 거리와 대기 시간이 포함된다.
6. **3층 자유 보행:** 맞이방→마루노바의 사선 `(1075,995)→(855,1145)`과 `to=49`의 `(855,1125)→(505,1215)`는 SVG 바닥·매장 도형에서 통과 가능한 것으로 판정됐다. 이동식 집기, 임시 차단, 실제 통로 폭은 현장에서 확인해야 한다.

현장 확인 결과는 원본 SVG·그래프를 덮어쓰지 않고 출처·일자·검증 상태와 함께 마이그레이션 데이터에 반영한다. `UNVERIFIED` 경로를 품질 KPI의 검증 성공으로 집계하지 않는다.
