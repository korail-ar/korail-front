우회는 안내 생성 이전의 **그래프 연결 관계**에서 시작됐다. `P26`은 서쪽의 `B05`에만 연결돼 있었고, `E034`는 `H06`을 통과하면서도 교차점으로 분리되지 않았다. SVG 평면도에서 매장 `3F-S10~S12`의 남쪽 경계는 y=1136.2 이하이며, 새 연결 `H07→(855,1145)→P26`은 그 아래 흰 보행 통로를 따른다. `E034`를 제거하고 `C01–H06`으로 분리했다. `A01–A02` 또한 `P10` 지점을 통과하는 간선이어서 `P10–A02`로 분리했다. 모두 양방향 일반 통로다. 새 연결은 현장 통행 검증 전 평면도 판독 결과로 표시한다.

경로 탐색은 실제 Edge 보행 거리 합을 우선 최소화하고, 동일 거리에서는 방향 상태별 회전 수가 적은 경로를 고른다. 화면 미리보기와 단계 안내는 동일한 `Route.points`를 사용한다. 화면 표시 경로를 별도로 X/Y 조합하여 직각화하지 않는다. 안내는 의미 있는 회전과 마지막 도착에서 생성하며 직진 중간 노드는 추가 단계가 되지 않는다.

## 1~4층 회귀 결과

`3F:C01`에서 각 층의 모든 그래프 노드를 대상으로 비교했다. 층간 회귀는 JSON의 이동 시간 가중치(엘리베이터 대기 및 수직 이동 추정 포함)를 사용했다. UI의 목적지 탐색은 현재 3층 시설에 연결돼 있다.

전체 152개 노드 중 150개에 도달한다. 2F의 2개는 기존 `2F-E012`가 통행 형상 미확인으로 비활성화되어 분리됐다. 확인되지 않은 간선을 임의로 복구하지 않았다. 2F로 향하는 검증된 엘리베이터 링크도 없어서 **2F 배리어프리 경로는 제공할 수 없다**. 1F·3F·4F 엘리베이터 경로의 그래프 연결은 유효하다. 계단과 에스컬레이터는 엘리베이터 전용 검사에서 제외했다.

층별 평면도의 직사각형 매장·서비스 시설·화장실 내부를 관통하는 활성 Edge는 0개였다. 활성 간선의 양 끝은 노드 좌표와 일치하고, Polyline 길이와 저장 거리의 오차는 허용 범위(0.15m) 안이다. 검증된 층간 링크는 모두 기존 노드에 연결되어 있고 방향 미확인 에스컬레이터는 비활성화된 상태를 유지했다. 3층 맞이방에서 모든 3층 노드까지의 최종 Polyline에 즉시 역주행은 없다.

단, 1F의 `1F-E023`, `1F-E025`, `1F-E026`, `1F-E027`, `1F-E029`는 건물 바닥 윤곽 밖을 지난다. 서쪽 야외 구간일 수 있으나 이 검사만으로 현장 보행 가능성을 확정할 수 없다. 이 5개는 현장 확인 대상이며 이번 변경에서 삭제하거나 임의로 우회시키지 않았다. 4F 위치 정합과 층간 접근부도 현장 측정 전 추정 상태다.
