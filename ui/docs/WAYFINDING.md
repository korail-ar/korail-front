# 대전역 길찾기 화면

Figma "Korail-Project" 공동작업 파일 중앙부의 W01~W11 화면을 구현했습니다. 지도는 디자인팀 2D 지도(`web-xF-map.svg`),
경로는 3층 보행 그래프(merged)를 씁니다. 모든 계산은 기기 안에서 하고 서버 호출은 없습니다.

## 화면과 주소

화면 사이에는 출발 위치(`start`)·목적지(`to`, place id)·타는 곳(`platform`)·단계(`step`)를 주소에 담아 넘깁니다.
QR 안내판은 `/?start=<id>` 주소를 담으면 됩니다(`START_POINTS`, `src/lib/station/data.ts`).

| Figma                       | 주소                             | 파일                                     |
| --------------------------- | -------------------------------- | ---------------------------------------- |
| W01 지도 중심 메인(QR 출발) | `/`                              | `src/app/HomeScreen.tsx`                 |
| W04 검색 결과               | `/search?q=&category=`           | `src/app/search/SearchScreen.tsx`        |
| W05 승강장 번호 선택        | `/platform`                      | `src/app/platform/PlatformScreen.tsx`    |
| W06 경로 미리보기           | `/route?to=`                     | `src/app/route/RouteScreen.tsx`          |
| W07 지도 길안내             | `/guide?to=&step=`               | `src/app/guide/GuideScreen.tsx`          |
| W08 랜드마크 단계 안내      | `/guide/steps?to=&step=`         | `src/app/guide/steps/StepListScreen.tsx` |
| W09 층 이동(승강장 분기)    | `/guide?…&platform=` 마지막 단계 | `GuideScreen.tsx`의 `FloorChangeView`    |
| W10 도착 · 시설 정보        | `/arrive?to=`                    | `src/app/arrive/ArriveScreen.tsx`        |
| W11 오류 · 출발지 재선택    | 경로를 못 만들 때 각 화면 대신   | `src/components/RouteError`              |
| (시안 없음) 출발 위치 선택  | `/start?next=`                   | `src/app/start/StartScreen.tsx`          |

흐름: 홈 → 검색(또는 타는 곳 번호) → 경로 확인 → 단계 안내(다음 단계 / 전체 단계 보기) → (승강장이면 층 이동) → 도착.

## 데이터

| 파일                                                           | 내용                                                                      |
| -------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `src/data/station/source/daejeon-station-3f-graph.merged.json` | 원본 복사본. `coordinate/3f/result/` (2026-11-20, sha256 `892b4b973b78…`) |
| `public/maps/web-{1..4}F-map.svg`                              | 디자인팀 2D 지도(Google Drive `daejeon-station-map/web`, 2026-11-24)      |
| `src/data/station/station3f.generated.json`                    | `npm run build:station` 결과. 직접 고치지 않습니다                        |

원본 x·y는 3D 렌더 이미지(2048×1386) 픽셀이라 2D 지도와 좌표계가 다릅니다. `scripts/build-station-data.mjs`가
이름이 같은 시설 41곳을 기준점으로 원근 변환 + thin-plate spline 보정을 해서 지도 좌표로 옮기고,
바닥 밖·방 안에 떨어진 노드는 가장 가까운 걷는 곳으로 옮깁니다. 기준점·예외는 스크립트 맨 위 표에 있습니다.

- **거리·시간:** 위경도가 있는 기준점끼리 실거리와 지도 거리를 비교해 1 지도 단위 ≈ 0.105m로 추정했습니다.
  걷는 속도는 분당 60m로 잡았고, 화면에는 항상 "약"을 붙여 5m/10m 단위로 보여줍니다.
- **이름:** 원본 이름이 설명형(`지도 위에서 두 번째 …`)이면 짝지어진 지도 마커 이름을 씁니다. 원래 이름으로도 검색됩니다.
- **접근 노드가 없는 시설**(화장실 일부 등)은 가장 가까운 노드까지 안내하고 "가까운 통로까지 안내" 문구를 붙입니다.
- **단계 안내:** 35° 이상 꺾이는 곳에서 나누고(8m 미만 구간은 합침), 18m 안의 지도 시설을 표지로 붙입니다.
  방향(왼쪽·오른쪽)은 지도 기준입니다.

## 확인이 필요한 것

데이터·도면 쪽(현장 확인 또는 데이터 담당 확인 필요):

1. **중앙 홀 ↔ 승강장 쪽 통로 연결:** 그래프에서 승강장 쪽 통로(B05~B07)가 중앙 홀(H07 등)과 이어져 있지 않아
   맞이방에서 5·6번 승강장으로 가는 경로가 북쪽 통로(B01–H03)로 크게 돌아갑니다. 실제로 바로 갈 수 있다면 간선을 추가해야 합니다.
2. **출구 번호가 서로 다릅니다:** 그래프는 서광장 쪽을 "1번 출구 방향", 디자인 지도는 "서광장·지하철 방향 (4번 출구)"이고
   동광장 쪽을 "동광장 방향 (1번 출구)"로 적었습니다. 화면에는 그래프 이름이 나갑니다.
3. **지도에 없는 시설:** 그래프의 화장실 7곳 중 3곳(마루노바·디자인스킨 인근, 남자화장실 P36), 고객 접견실, 휴게실2,
   편의시설 아이콘 2곳은 디자인 지도에 없습니다. 변환 위치로만 표시됩니다.
4. **승강장 1·2번:** 디자인 지도에 "미운행"으로 표시되어 있어 번호 선택에서 고를 수 없게 했습니다.
5. **승강기 C:** 디자인팀 전달대로 3층에서 확인되지 않아 3층 지도에는 없습니다(1·3층 정합 확인 필요).
6. **경로는 3층만:** 1·2·4층은 지도만 보여줍니다. 층별 그래프가 생기면 `findRoute`를 층 간 이동까지 넓혀야 합니다.

디자인 쪽:

1. **W01 3D 지도:** 시안의 3D 도식(Figma 이미지)은 쓰지 않고 2D 지도(`web-3F-map`)로 넣었습니다(디자인팀 전달 사항).
   "2D 보기" 전환 버튼과 "현위치" 빨간 핀은 넣지 않았습니다. 출발 위치는 QR 마커와 이름표로 보여줍니다.
2. **정류장 바로가기:** 지금은 "지하철·도시철도" 별칭이 붙은 시설(서광장 1번 출구 방향)을 보여줍니다.
   연계교통 기능을 넣지 않으면 `QUICK_FILTERS`에서 지우면 됩니다.
3. **W05 타는 곳 번호:** 시안은 1~8번이지만 지도에 11·12번 홈까지 있어 1~12번을 보여줍니다.
4. **W10 시설 정보:** 운영 시간 등 시설 정보 데이터가 없어 분류와 출발 위치에서 걸리는 시간을 보여줍니다.
5. **출발 위치 선택 화면:** 시안이 없어 기존 컴포넌트(ResultItem)로 만들었습니다. QR 설치 자리도 예시 4곳입니다.
