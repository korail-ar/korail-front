## 전체 그래프 회귀

### 층별 QA (2026-11-27)

각 층의 활성 간선 양 끝을 실제 TypeScript 엔진으로 탐색해 최종 선형의 공간 검사와 안내 선형 일치를 확인했다. 4층 모두 통과해 내비게이션 테스트는 **47개 통과**했다. 아래 전수 집계는 출발 층 기준이며, 같은 층과 층간 목적지를 모두 포함한 JSON 그래프 회귀 결과다. `UNVERIFIED`는 현장 검증 성공을 뜻하지 않는다.

| 3F | 78 / 80 | 11,700 / 156 | 10,452 / 1,404 | 마루노바·계단/에스컬레이터 및 QR×59시설 경로 통과; 연결 후보 경고 7건 |

각 층의 개선 그래프 거리에서 원본 기준 대비 10% 초과 증가한 데이터 경로는 0건이며, 회귀 `FAIL`도 0건이었다. 개발자 검증 화면은 브라우저에서 3F 기본 경로까지 확인했다. 자동화 도구의 층 버튼 클릭 오류로 **1F·2F·4F의 화면별 시각 검증은 수행하지 못했다**. 따라서 위 층별 통과는 데이터 및 엔진 검증 결과로 한정한다.

원본 152노드, 마이그레이션 153노드(검증된 교차점 1개 추가). 1~4층 전체 방향별 23,256쌍을 일반 및 배리어프리 모드로 각각 검사했다. 이 검사는 JSON 그래프 최단 거리와 접근성 제약을 비교하는 데이터 수준 회귀 검사다. TypeScript 최종 경로 및 화면의 모든 쌍을 E2E로 실행했다는 뜻이 아니다.

2층 E012는 원본에서 비활성화된 빈 형상으로 유지했다. 2층 고립 노드 2개와 검증된 2층 엘리베이터 연결 부재는 경고로 기록했다. 검증되지 않은 연결을 생성해 도달률을 높이지 않았다. 현장 검증되지 않은 경로는 모두 `UNVERIFIED`이며 성공 KPI로 집계하지 않는다.

## 남은 검증

- 1·2·4층에는 현장 검증된 시설 출입구 데이터가 없다. 현재 운영 목적지 목록은 기존 3층 59개 시설을 유지한다.
- 출입구 중심 좌표와 실제 문 위치는 구분했지만 실제 문 좌표는 미확인이다. 배리어프리 시설 접근성도 확인 전에는 확정하지 않는다.
- SVG 보행 영역과 축척은 추정 자료다. 통로 폭, 계단 및 에스컬레이터 운영 방향, 엘리베이터 정차 층과 대기 시간은 현장 확인이 필요하다.
- 모바일 브라우저 E2E는 아직 실행하지 않았다. 개발자 페이지의 프로덕션 404는 로컬 빌드에서 확인했으며 실제 배포 환경의 응답은 별도 검증이 필요하다.
