# ui

- 프론트엔드 작업은 이 폴더 안에서만 합니다. 저장소 루트의 기존 웹앱(백엔드 작업자)은 건드리지 않습니다.
- 작업 규칙: [`AGENTS.md`](AGENTS.md)
- 코드 컨벤션: [`docs/CONVENTIONS.md`](docs/CONVENTIONS.md) (Airbnb 스타일 가이드 기준)
- 브랜치: `frontend` (프론트엔드의 main)
