대전역 평면도 좌표 표시본

기존 93개 도면 지점 + 이번 추가 14개 = 107개 도면 지점.
추가 14개는 계단 6개, 에스컬레이터 1개, 용도 미확인 공간 7개다.
새 점은 원본 SVG 도형 경계상자의 중심이며 출입구나 현장 측량점이 아니다.
중복을 줄이기 위해 기존 지점이 도형 경계 안 또는 경계에서 5 native 단위 이내에 있는 경우 추가하지 않았다.

파일
floor_1~4_marked.png: 확인용 이미지. 파란 표식은 기존 지점, 보라 X 표식은 이번 추가.
floor_1~4_marked.svg: 원본 SVG 좌표계를 유지한 표시본. 표의 X/Y는 이 SVG viewBox의 좌표다.
PNG는 보기 좋게 크기를 바꿨으므로 PNG 자체의 픽셀 좌표와 표의 X/Y를 혼용하면 안 된다.
floor_points_expanded.json: 기존 좌표와 추가 좌표, 출처 도형 ID, GPS 상태.
daejeon_facility_coordinates.xlsx: 도면좌표 107개, 네이버등록좌표 8개, 기존시설대조 89개.

GPS
지도 위도/경도는 이전 작업에서 네이버 개별 POI를 확인한 항목만 입력했다.
추정 위도/경도는 이전 아핀 변환을 사용한 미검증 후보이며 실제 GPS 또는 현장 정확도를 뜻하지 않는다.
현재 지도-도면 정합이 맞지 않는 항목이 있어 길안내용 확정 좌표로 쓸 수 없다.
새로운 네이버 검색은 이번 작업에 포함하지 않았다.

분류
이름이 없는 공간에 임의의 시설명을 붙이지 않았다.
동일 시설 단지에 여러 계단 도형이 있을 수 있으므로 추가 도형 수가 서로 다른 시설 수를 뜻하지 않는다.
남녀 구분, 승강기 연결층, 계단 상하행, 출입구, 통행 가능 여부는 현장 확인이 필요하다.
기존 시설 목록과 도면의 층이 충돌하는 물품보관소·유실물센터 등은 기존시설대조 시트에 후보로 남겼다.
